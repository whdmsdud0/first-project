### 스칼라
- 숫자를 의미
- 5,0,0.4,-1도 모두 스칼라가 될 수 있음

### 벡터
- 벡터는 숫자들을 정해진 순서로 모아놓은 것
- ex) [5,2]
- 세영이의 출석은 5일, 과제는 2개를 제출했다면 이 두 가지 정보를 함께 묶고 싶을 때 [5,2]로 묶을 수 있다

### 벡터의 차원
- [5,2]는 숫자가 2개이므로 2차원 벡터라고 부른다.
- [5,2,4]는 숫자가 3개이므로 3차원 벡터라고 부른다.

### Shape 배열
- Shape는 각 축에 값이 몇 개씩 놓여있는 지를 알려주는 정보
- x.shape = (2,)

### 행 벡터와 열 벡터
- 행 벡터는 값을 한 행에 가로로 놓은 형태, 열 벡터는 한 열에 세로로 놓은 형태

### reshape
- reshape는 배열의 값과 전체 원소 개수를 유지하면서 배치를 바꾸는 기능
- x = np.array([5,2])에서 x.shape(1,2)는 [[5,2]], x.reshape(2,1)은 [[5],[2]]를 만든다.

### 가중치 w
- 가중치는 각 입력값에 곱하는 값
- 어떤 입력이 점수 계산에 어떻게 반영되었는 지 조절함
- 참여 점수를 출석 하루당 2점, 과제 하나당 3점이라고 했을 때
- 세영이가 5일 출석했다면 5 x 2 = 10점을 받을 수 있다. 과제를 2개 냈다면 2 x 3 = 6점이다
- 그래서 16점을 받을 수 있었다.

### 편향 b
- 편향은 입력값에 가중치를 곱해 더한 결과에 추가로 더한 값
- 참여 점수를 계산할 때 모든 학생들에게 기본 점수 1점을 준다는 가정이라면
- 출석을 아예 하지 않은 하영은 0 x 2 + 0 x 3 + 1로 1점을 받을 수 있다.

### 파라미터
- 파라미터는 모델의 계산에 사용되며 학습으로 조정할 수 있는 값(가중치와 편향)
- 예를 들어 공부 시간으로 시험 점수를 예상한다고 가정해보면
- 예상 점수 = 공부시간 x 5 + 10 <- 이라는 기본 규칙에서
- 실제 2시간 공부한 학생의 예상 점수는 20점인데, 실제로 30점이라면 두 점수 차이를 계산하여
- 이를 조정하는 값

### 가중합과 출력 점수
- 가중합은 각 입력값에 대응하는 가중치를 곱한 뒤 모두 더한 값
- 아까 앞서 5 x 2 = 10점, 2 x 3 = 6점, 편향 1점 이면 17점
- 여기서 16점이 가중합이라고 부를 수 있다.

### 가중치 행렬
- 가중치 행렬은 여러 출력에 필요한 가중치들을 표로 모은 것
- w =[[2,1],[3,4]]라고 가정하면 같은 출석, 과제 기록으로 점수를 만든다고 할 때
- 첫 번째 점수는 출석당 2점, 과제당 3점, 둘째 점수는 출석당 1점, 과제당 4점으로 나타낼 수 있다.

### 노름 L1 Norm 
- L1 노름은 각 원소의 절대값을 구한 뒤 전부 더한 값
- 윤하가 오른쪽으로 3m 이동한 뒤 아래쪽으로는 4m 이동했다고 가정하면 이동 기록은 [3, -4]일 수 있다.
- 이걸 이동 거리로 계산해보면 |3|, |-4|, L1 노름을 이용하면 3 + 4 = 7m 이동했다고 볼 수 있다.

### 노름 L2 Norm
- L2 노름은 각 원소를 제곱하고 모두 더한 뒤, 제곱근을 구한 값
- 8강의실 출입문을 [0,0]으로 정하고 윤하가 오른쪽 6m , 위쪽 8m 지점에 있다고 가정을 해보면
- 출입문에서 윤하까지의 거리는 6 x 6 = 36, 8 x 8 = 64, 36 + 64 = 100 <- 루트를 써서 10m 정도 떨어져 있더는 것을 구할 수 있다.

### 차이 벡터
- 차이 벡터는 두 벡터에서 같은 위치의 값끼리 뺀 결과
- A = [3,4], B = [6,8]일 때, B - A = [6-3, 8-4] = [3,4]로 계산할 수 있다.

### 맨해튼 거리
- 맨해튼 거리는 두 벡터의 같은 위치 값끼리 차이를 구하고, 그 차이의 절대값을 모두 더한 값
- A = [3,4], B = [6,8]이면 치아 = [3,4] / 절대값은 3과 4 / 합은 7로 7m의 거리를 가진다.
- 가로 세로 통로를 따라 움직이는 상황에서 각 방향의 차이를 더해 거리를 구한다.

### 유클리드 거리 L2 거리
- 유클리드 거리는 두 점 사이의 직선거리 방식으로 구한 차이의 크기
- A = [3,4]고 B = [6,8]이면 차이는 [3,4]인데 이걸 제곱하면 9, 16이고 두 값을 더해 루트 게산을 하면 5m 정도로 구할 수 있다.

### 벡터의 방향과 비율
- 방향은 벡터가 원점에서 어느 쪽을 가리키는 지를 말한다.
- A = [3,4], B = [6,8]이면 B의 값은 A의 2배이다. 두 값의 비율은 3:4, 6:8로 같다.

### 스칼라 벡터 행렬
- 스칼라와 벡터, 행렬에 대한 차이를 구분할 수 있다.
- 스칼라 = 숫자 하나
- 벡터 = [3,2] 원소를 2개 가지는 벡터
- 행렬 = [[3,2],[5,1],[2,4]] = 3행 2열의 행렬

### 벡터의 내적 Dot Product
- 벡터 내적은 같은 위치의 숫자끼리 곱한 뒤, 곱셈 결과를 모두 더하는 계산
- 영흠의 출석 과제 점수 기록을 [3,2]와 점수 규칙 [2,4]를 내적해본다고 가정하면
- 출석 점수는 3 x 2 = 6점
- 과제 점수는 2 x 4 = 8점
- 최종적으로 14점

### 사이각과 각도
- 사이각은 두 벡터를 같은 출발점에서 그렸을 때 두 방향 사이에 벌어진 각도
- 0은 같은 방향 90은 직각, 180은 정반대 방향(1,0,-1)

### 코사인 유사도
- 코사인 유사도는 두 벡터의 내적을 두 길이의 곱으로 나누어 방향 관계를 비교하는 값
- 학생의 [국어, 수학] 문제 수가 민수 [3, 4], 지수 [6, 8]이면
- 내적은 3 x 6 + 4 x 8 = 50, 각 길이는 5와 10이기 때문에 50 / 5 x 10 = 1

### 행렬곱
- C11 = A11 X B11 X A12 X B21
- C = A @ B에서 C11은 A의 1행 1,2와 B의 1열 [5,7]을 내적한다.
- 1 X 5 + 2 X 7 = 19
- 앞에 열과 뒤에 행수가 같아야 함
- (3,2) @ (2,4)는 가능하지만 (2,4) @ (3,2)는 불가능 함

- 공부를 시작한 뒤 처음 2시간은 기초를 익히기 때문에 점수 상승을 기대하기 어렵다.
- 기초를 충분히 파악한 2시간 뒤부터 점수가 올라갈 것이다.
> h = x - 2 

> y = 50 + 10h

> h = ReLU(x-2) = max(0, x-2)

> 공부시간 0시간 일 때
x - 2 = -2, ReLU를 적용하면 0, 최종 점수 = 50

> 공부시간이 1시간 일 때
x - 2 = -1, ReLU를 적용하면 0, 최종 점수 = 50

> 공부시간이 2시간 일 때
 X - 2 = 0, ReLU를 적용하면 0, 최종 점수 = 50

> 공부시간이 3시간 일 때 
X - 2 = 1, ReLU를 적용하면 1, 최종 점수 = 60

> 공부시간이 4시간 일 때
X - 2 = 2, ReLU를 적용하면 2, 최종 점수 = 70

> 2시간 이하의 공부시간이라면 굳이 패턴을 파악하지 않고 50점 유지
> 2시간 초과의 공부시간이라면 시간에 따른 점수 증가

### 딥러닝 예시 - 공부 기록으로 시험 점수를 예측하는 신경망 만들기

> 입력값은 3개 (공부시간, 풀어본 문제 수, 복습 횟수)
> 값은 (2,3,1)이라고 가정
> 신경망에 사용되는 데이터 X1, X2, X3 = [2,3,1]

> 은닉층은 2개 뉴런은 3개를 사용하여 딥러닝을 구성해보겠다.
> 1. 세 뉴런모두가 X의 특성값인 [2,3,1]을 받는다.
> 단, 각각의 뉴런은 가중치와 편향이 다르기 때문에 다른 결과를 얻는다.

> 첫 번째 뉴런, 가중치는 [1,1,-1] 편향은 -1로 가정하면
> z1 = (1 x 2) + (1 x 3) + (-1 x 1) - 1 = 3
> h1 = ReLU(3) = 3

> 두 번째 뉴런, 가중치는 [-1,1,1] 편향은 0으로 가정
> z2 = (-1 x 2) + (1 x 3) + (1 x 1) + 0 = 2

> 세 번째 뉴런, 가중치는 [1,-1,-1], 편향은 1로 가정
> z3 = (1 x 2) + (-1 x 3) + (-1 x 1) + 1 = -1
> h3 = ReLU(-1) = 0

|뉴런| 가중합 + 편향| ReLU 적용 후|
|---|---|---|
|뉴런 1| 3 |3|
|뉴런 2| 2 |2|
|뉴런 3| -1 |0|

- 첫 번째 은닉층의 출력값은 [3,2,0] 값
- 두 번째 은닉층에서 사용할 중간값을 의미한다.

- 두 번째 은닉층 : 앞에서 나온 중간값[3, 2, 0]을 받는다.
- 첫 번째 뉴런 : 첫 번째 은닉층은 원래 데이터 [2,3,1]을 받았지만 두 번째 은닉층에서는 첫 번째 은닉층의 결과인 [3,2,0]을 받아서 계산한다.

- u1 = (1x3) + (1x2) + (1x0) - 1 = 4
- a1 = ReLU (4) = 4

- 두 번째 뉴런 : 
- u2 = (-1 x 3) + (1 x 2) + (1 x 0) + 0 = -1
- a2 = ReLU(-1) = 0

- 세 번째 뉴런 : 
- u3 = (1 x 3) + (-1 x 2) + ( 1 x 0) + 1 = 2
- a3 = ReLU(2) = 2

|뉴런| 가중합 + 편향| ReLU 적용 후|
|---|---|---|
|뉴런 1|4|4|
|뉴런 2|-1|0|
|뉴런 3|2|2|

- 두 번째 은닉층의 출력은 [4,0,2]
- 두 개의 은닉층을 활용하여 최종 출력층을 만들어본다면
- 출력층은 마지막(두 번째 은닉층)에서 나온 [4,0,2]를 받는다.
- 출력층도 마찬가지로 뉴런의 가중치를 [10,-5,5], 편향을 20이라고 가정해보면
- y = (10 x 4) + (-5 x 0) + (5 x 2) + 20  = 70점
- 최종 예측 점수는 70점으로 볼 수 있다.

### 지금 까지의 순서 정리
- 1. 입력층 -> 학생의 정보 전달 -> [2,3,1]
- 2. 첫 번째 은닉층 -> 뉴런 3개가 각 가중합과 편향 계산 -> [3,2,-1]
- 3. 첫 번째 은닉층 -> 뉴런 3개가 각 가중합과 편향을 계산 -> [4,-1,2]
- 4. 두 번째 은닉층 -> 뉴런 3개가 각 가중합과 편향을 계산 -> [4,-1,2]
- 5. 두 번째 은닉층의 ReLU -> 음수 결과를  0으로 변경 -> [4,0,2]
- 6. 출력층 -> 마지막 가중합과 편향을 계산 -> 예측 점수 70점

- 출력층의 예측 점수와 실제 점수를 비교한 뒤 가중치와 편향을 수정한다.
- 이 학생의 실제 점수가 80점이었다면
- 예측값 : 70점
- 실제 정담 : 80점
- 제곱 오차 = (70 - 80)^2 = 100
- 이 오차를 바탕으로 다시 각 가중치와 편향의 기울기 계산
